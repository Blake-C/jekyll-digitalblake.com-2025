<p>A running list of the hardware, apps, and command-line tools I reach for every day. Almost all of it is symlinked from my dotfiles and installed by a single bootstrap script when I set up a new Mac, so the setup is the same on every machine I touch.</p>

## Hardware

<ul>
	<li>An Apple Silicon Mac.</li>
</ul>

## Editor and AI

<ul>
	<li><strong>Visual Studio Code</strong> is my primary editor.</li>
	<li><strong>Neovim</strong> for quick edits without leaving the terminal.</li>
	<li><strong>Claude Code</strong> is the agent I run in the terminal for larger, multi-file work. This site was built with it.</li>
	<li><strong>Ollama</strong> runs models locally so I can work offline and keep code on the machine.</li>
</ul>

## Terminal and shell

<ul>
	<li><strong>iTerm2</strong> as the terminal emulator.</li>
	<li><strong>zsh</strong> with the <strong>Powerlevel10k</strong> prompt.</li>
	<li><strong>tmux</strong> for splitting and persisting sessions.</li>
	<li><strong>fnm</strong> switches Node versions per project; <strong>pyenv</strong> does the same for Python.</li>
	<li><strong>Homebrew</strong> and <strong>pnpm</strong> for package management.</li>
</ul>

## Window management and keyboard

<ul>
	<li><strong>yabai</strong> for tiling window management.</li>
	<li><strong>Karabiner Elements</strong> for keyboard customisation.</li>
</ul>

{%- comment -%} Avatar for a testimonial. Renders the photo when `avatar` is set on the entry in _data/testimonials.yml, and initials otherwise. Decorative either way: the name is adjacent text, so alt is empty and the initials are hidden from assistive tech to keep a screen reader from reading the person twice. {%- endcomment -%} {%- assign name_parts = include.testimonial.name | split: ' ' -%} {%- assign initials = name_parts[0] | slice: 0 -%} {%- if name_parts.size > 1 -%} {%- assign second_initial = name_parts[1] | slice: 0 -%} {%- assign initials = initials | append: second_initial -%} {%- endif -%} {%- if include.testimonial.avatar -%} {%- else -%} {{ initials | upcase }} {%- endif -%}
